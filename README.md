# GigTry — Autonomous AI Tools Platform

**Live site: [https://www.gigtry.com](https://www.gigtry.com)**

GigTry is a self-running AI tools marketplace: 89 production-grade AI tools (text, image, video, code, audio, productivity) across 4,450+ localized city landing pages, served on a 100% free-tier serverless stack ($0/month infrastructure).

## What makes it different

- **Autonomous content engine** — generates and publishes SEO blog articles daily from live trend research (Google Trends, Hacker News, Reddit, Google News — all keyless/free), with compliance hard-gates and rate limits.
- **Free-tier maximalist architecture** — Next.js 16 on Vercel Hobby, Supabase Postgres, Groq for inference. Everything runs inside the free tiers of the platforms it uses.
- **Measurable everything** — server-side GA4 Measurement Protocol events for the full funnel (tool run → checkout → purchase), IndexNow pings on every publish, RSS + sitemap + llms.txt surfaces.
